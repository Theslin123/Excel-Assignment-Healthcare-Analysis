# Healthcare Data Analysis

# Project Overview
This project focuses on analyzing healthcare data to identify patterns in patient health conditions, medical examinations, hospitalization details, and healthcare charges. The objective is to transform raw data into meaningful insights that support better healthcare decision-making.
# Project Objectives
* Cleaning missing values and handling inconsistencies in the data set.
* Transform and organize data for analysis.
* Combine multiple tables using Customer ID.
* Calculate patient age and categorize BMI and HbA1c levels.
* Analyze relationships between health indicators and healthcare charges.
* Create pivot tables, charts, and an interactive dashboard.
 # Tools Used
* Microsoft Excel
* Pivot Tables and Pivot Charts
* Excel Formulas and Functions
* Data Cleaning and Transformation
* Data Visualization
  # Dashboard
  An interactive healthcare dashboard summarizes the key findings through charts, KPI cards, and Slicers.
  The dashboard is designed to help users explore healthcare charges, patient health indicators, and differences across hospital tiers and states.
  # Key Learning Outcomes
  * Practiced data cleaning and transformation.
  * Improved Excel formula and lookup-function skills.
  * Learned to create pivot tables and pivot charts.
  * Developed skills in Dashboard design.
